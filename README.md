# Magnet Of Valor — ชุดแก้ไขหน้า Admin และเงินรางวัล

## ติดตั้ง
1. สำรอง repository เดิมก่อน
2. แตก ZIP แล้วอัปโหลดไฟล์ข้างในทั้งหมดไว้ระดับเดียวกับ index.html ของโปรเจกต์
3. ห้ามอัปโหลดเฉพาะ ZIP หรือวางไฟล์ไว้ในโฟลเดอร์ซ้อนอีกชั้น
4. ชุดนี้ใช้ admin.html ตัวเล็กเป็นหน้าจัดการจริงเพียงไฟล์เดียว ป้องกันชื่อไฟล์ชนกันบน Windows
5. อัปโหลด vercel.json ด้วย เพื่อส่ง /Admin.html และ /admin ไป /admin.html
6. รอ Vercel Deploy commit ใหม่เป็น Ready แล้วเข้า /admin.html
7. หน้าล็อกอินต้องแสดงข้อความเวอร์ชัน 2026-09-10; หลังล็อกอินจะเห็นแท็บทีม แมตช์ ลิงก์และประกาศ

หาก repository ยังมี Admin.html เก่า ให้สำรองไว้แล้วนำไฟล์เก่านั้นออกจากโปรเจกต์ที่เผยแพร่ ใช้ admin.html ชุดนี้แทน
ไฟล์ในโฟลเดอร์ MagnetOfValor-Firebase-Admin เดิมเป็นชุดซ้ำ ไม่ใช่ตำแหน่งติดตั้งของชุดนี้
Vercel Root Directory ต้องชี้โฟลเดอร์ที่มี index.html และ admin.html ชุดนี้
หากยัง 404 ให้ตรวจว่า deployment ล่าสุดมี admin.html จริง และ domain ชี้ deployment นั้น

## สิ่งที่แก้
- รวมไฟล์ซ้ำให้เหลือชุดเดียว และใช้หน้า Admin ตัวเต็มแทนไฟล์ส่งต่อที่ไม่มีปลายทาง
- คง index.html ที่แก้ไขล่าสุดในโฟลเดอร์ย่อยของ ZIP และคง Firebase Config/UID เดิม
- เงินรางวัลรวมและอันดับต่าง ๆ แสดง -฿ รวมถึงข้อความเงินรางวัลที่ยังพบในหน้าเว็บ
- แยกข้อความกำลังตรวจการล็อกอิน/กำลังเชื่อมต่อ/บันทึกสำเร็จให้ดูได้ชัด
- แสดงข้อความช่วยเหลือหากเปิดไฟล์ในเครื่องแทน HTTPS

## ข้อมูล Firebase
ใช้ settings/tournament เหมือน PART 2 เดิม: teams, matches, links, announcement, revision, updatedAt
การติดตั้งไฟล์นี้ไม่ลบหรือรีเซ็ตข้อมูลบน Firebase
Firebase SDK ต้องใช้อินเทอร์เน็ต; ไม่ต้อง npm
อย่าเปลี่ยน Firestore Rules ให้ทุกคนเขียนได้ ให้คง Rules ที่ตรวจ UID แอดมินเดิม
ทุกฟิลด์ใน settings/tournament เป็นข้อมูลสาธารณะ ห้ามใส่รหัสผ่าน/เบอร์โทร/ข้อมูลสมัครส่วนตัว

## วิธีใช้
- ทีม: ตัวจริง 5 คน กัปตัน 1 คน สำรองไม่เกิน 2 คน; Win/Lose ว่างจะคำนวณจากแมตช์
- แมตช์: ตั้ง completed พร้อมคะแนนครบ BO เพื่อเลื่อนทีม; Grand Final BO7 ชนะถึง 4
- ลิงก์และประกาศ: ใส่ URL เต็ม แล้วบันทึก หน้าผู้ชมรับข้อมูลใหม่อัตโนมัติ
- PDF: ใส่ลิงก์ PDF ของคุณในช่อง PDF กติกาฉบับล่าสุด ไฟล์ PDF ภายนอกไม่ได้ถูกแก้ด้วยชุดนี้
- เงินรางวัลในประกาศที่เคยบันทึกลง Firebase ให้แก้เป็น -฿ จากแท็บลิงก์และประกาศด้วย
- ไม่มี Group Stage / Round Robin เพิ่มเติม

## ตรวจหลัง Deploy
เปิด /admin.html → ล็อกอิน → ลองบันทึกข้อมูล → เปิดหน้าผู้ชมตรวจผล
หากแจ้งเวอร์ชันข้อมูลเปลี่ยน ให้โหลดค่าล่าสุดในแท็บนั้นก่อนแก้ใหม่
หาก permission-denied ให้ตรวจโปรเจกต์/UID/Rules; หากโหลดระบบไม่ได้ให้ตรวจไฟล์และอินเทอร์เน็ต

ได้ตรวจไฟล์และทดสอบตรรกะภายในเครื่องแล้ว ยังไม่ได้ล็อกอินหรือเขียนลง Firebase จริงของคุณ
