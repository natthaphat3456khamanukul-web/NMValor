# Magnet Of Valor — Firebase Admin + Public Website

## ติดตั้ง
1. สำรองไฟล์เดิมของคุณก่อน
2. แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ root เดิมของ repository GitHub (ไม่ใช่อัปโหลด ZIP ทั้งก้อน)
3. หน้าผู้ชมต้องชื่อ index.html ไม่ใช่ index(2).html
4. รอ Vercel deploy commit ใหม่ให้สำเร็จ
5. เปิด https://โดเมนจริงของคุณ/Admin.html (A ตัวใหญ่) และล็อกอินด้วยบัญชี Firebase เดิม
6. ลิงก์ /admin.html ตัวเล็กมีหน้าเปลี่ยนเส้นทางไป /Admin.html ให้ด้วย
7. เปิด index.html อีกแท็บเพื่อดูข้อมูลเปลี่ยนหลังบันทึก

ใช้ Firebase Config และ Admin UID จาก Admin.html ที่คุณส่งมาแล้ว ไม่ต้องใส่ใหม่
ไม่มีรหัสผ่านหรือ service-account private key ในชุดนี้ รหัสผ่านใส่เฉพาะตอนล็อกอิน
Firebase SDK โหลดจาก CDN ต้องใช้อินเทอร์เน็ตและเปิดผ่านเว็บ HTTPS; ไม่ใช้ npm
กฎ Firestore เดิมที่จำกัด write ด้วย Admin UID รองรับชุดนี้ ไม่ต้องเปิด write ให้ทุกคน
ข้อจำกัด API Key ต้องอนุญาตโดเมน Vercel จริงทุกโดเมนที่คุณใช้งาน

## จุดเก็บข้อมูล (สำคัญ)
ชุดนี้ใช้เอกสาร settings/tournament เป็นแหล่งข้อมูลสาธารณะร่วมกันทั้งสองหน้า
ประกอบด้วย teams, matches, links, announcement, revision และ updatedAt
สร้างเอกสารให้อัตโนมัติเมื่อบันทึกทีม/แมตช์/ลิงก์ครั้งแรก ไม่ต้องสร้างด้วยมือ
adminMeta/status เก็บประวัติล็อกอินตามเดิมและเป็นข้อมูลส่วนตัวภายใต้ Rules ของคุณ
ไม่ได้อ่านหรือย้ายข้อมูลจาก collection teams / matches / announcements เดิมให้อัตโนมัติ
หากเคยกรอกข้อมูลใน collection เหล่านั้นไว้ ข้อมูลเดิมไม่ถูกลบ แต่จะยังไม่แสดงในชุดนี้
การรวมข้อมูลสาธารณะทัวร์นาเมนต์ 16 ทีมไว้ในเอกสารเดียวทำให้ตรวจสายแข่งขันและบันทึกพร้อมกันได้
ทุกครั้งที่เขียนใช้ transaction พร้อม revision ป้องกันการเขียนทับข้อมูลเก่าจากหลายแท็บ
หากแจ้งว่าเวอร์ชันเปลี่ยน ให้เลือกแท็บ/ทีมเดิมใหม่ หรือกดโหลดค่าล่าสุด แล้วแก้อีกครั้ง
ข้อมูลนี้อ่านได้ทั้งเอกสาร ห้ามใส่เบอร์โทร อีเมล ข้อมูลสมัครส่วนตัว หรือรหัสผ่าน

## จัดการทีม
- รหัสทีมใช้ภาษาอังกฤษ ตัวเลข - หรือ _ และเปลี่ยนไม่ได้หลังสร้าง
- รับได้สูงสุด 16 ทีม; ชื่อทีมและ Seed ห้ามซ้ำ
- ตัวจริงครบ 5 คน กัปตันแยก 1 คน สำรองไม่เกิน 2 คน รวมไม่เกิน 8 คน
- กรอกชื่อกัปตันที่ยินยอมเผยแพร่ และ IGN/ตำแหน่งของผู้เล่น
- Seed ว่างคือยังไม่จับสาย; 1 พบ 2, 3 พบ 4 ตามลำดับใน R16
- Win/Lose ว่างคำนวณจากแมตช์ที่จบแล้ว; ใส่ตัวเลขจะใช้ค่าที่กรอกแทน
- K/D/A คือยอดรวมที่กรอกเอง ไม่ได้เชื่อม API เกม
- หากจะลบทีมที่มีแมตช์ ต้องลบ/แก้แมตช์อ้างอิงก่อน
- เปลี่ยนสถานะทีม (ยืนยัน/กำลังแข่งขัน/ตกรอบ/แชมป์) ได้เอง สถานะไม่ได้เปลี่ยนอัตโนมัติตามผล

## แมตช์
- R16 BO1, R8 BO3, Semifinal BO3, Third Place BO3, Grand Final BO7
- เลือกคู่แล้วใส่ทีม คะแนน สถานะ วันเวลาไทย และลิงก์เฉพาะแมตช์
- completed ต้องมีผู้ชนะครบ BO (1, 2 หรือ 4 เกม) และมีทั้งสองทีม
- ผู้ชนะเลื่อนไปคู่ถัดไป ผู้แพ้ semifinal ไปชิงอันดับ 3
- แก้ผลเก่าที่ขัดกับแมตช์รอบถัดไปจะถูกปฏิเสธ ต้องแก้หรือลบแมตช์ปลายทางก่อน
- ลบแมตช์คือเอาผลที่บันทึกออก ไม่ลบช่องในแผนผัง; ทีมอาจยังแสดงตาม Seed/ผลรอบก่อน
- รองรับแพ้คัดออกเท่านั้น ยังไม่สร้าง Round Robin, ตารางกลุ่ม, tie-break หรือ cross-bracket อัตโนมัติ

## ลิงก์และประกาศ
กรอก URL เต็ม https://... ไม่ต้องใส่เครื่องหมายคำพูด
มีฟอร์มสมัคร, ถ่ายทอดสดหลัก, Discord, Facebook, Instagram และ PDF กติกา
PDF: ใส่ลิงก์ไฟล์กติกาฉบับแก้ไขของคุณ ปุ่มเดิมอ้างถึงข้อมูลที่หายไปจึงซ่อมให้ใช้ URL นี้
ถ้ายังไม่กำหนดลิงก์ PDF จะมีข้อความแจ้งและยังอ่านกติกาใน Rules ได้
หัวข้อและรายละเอียดประกาศแก้ได้จากแท็บนี้ ส่วนกำหนดการ/กติกาฉบับเต็มยังเป็นข้อความใน index.html
กติกาที่อยู่ในหน้าเดิมอาจกล่าวถึง Group Stage แต่แผนผังปัจจุบันยังเป็นแพ้คัดออก
การรับสมัครยังเปิดฟอร์มภายนอก ไม่ส่งอีเมลรหัสทีม ไม่ดึงคำตอบฟอร์มเข้า Firebase อัตโนมัติ

## ตรวจหลัง Deploy
1. เข้าหน้า Admin แล้วรอข้อความพร้อมจัดการข้อมูล
2. เพิ่มทีมทดสอบ 1 ทีม โดยกรอกตัวจริง 5 คนและกัปตัน แล้วกดบันทึก
3. เปิดหน้าผู้ชมแบบไม่ล็อกอิน ต้องเห็นทีมและกัปตันโดยไม่ต้อง reload
4. ใส่ลิงก์ Discord และประกาศ แล้วตรวจหน้า Home
5. ทดสอบ logout: ฟอร์มจัดการต้องหายไปและกลับหน้า login
6. Rules Playground: ผู้ไม่ล็อกอินและ UID อื่นต้องเขียน settings/tournament ไม่ได้; Admin เขียนได้

## ข้อผิดพลาด
- permission-denied: ตรวจว่า Rules ที่ Publish ในโปรเจกต์นี้ใช้ UID แอดมินตรงกัน
- auth/*: ดูรหัสที่ขึ้น ตรวจบัญชี อินเทอร์เน็ต โดเมน และข้อจำกัด API Key
- โหลดระบบไม่สำเร็จ: ตรวจว่าไฟล์ .js/.css อยู่ครบในโฟลเดอร์เดียวกัน และ CDN ไม่ถูกบล็อก
- บันทึกขึ้นเว็บไม่ได้เมื่อออฟไลน์: เชื่อมต่อใหม่และโหลดหน้าใหม่
- ข้อมูลจากเซิร์ฟเวอร์ไม่ถูกต้อง: ตรวจ settings/tournament อย่าแก้ JSON สุ่ม

ทดสอบโค้ดและการตรวจข้อมูลในสภาพแวดล้อมจำลองแล้ว แต่ไม่ได้ล็อกอินหรือเขียนข้อมูลลง Firebase จริงของคุณ
